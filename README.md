# BazarDor (বাজার দর)

## Description
BazarDor is a web application that helps users check daily market prices of essential products in Bangladesh.

## Technologies Used
- Next.js
- React
- JavaScript
- Tailwind CSS
- DaisyUI
- MongoDB
- Better Auth

## Features
1. View daily product prices.
2. Browse products by category.
3. Track price increases and decreases.
4. View top-priced products.
5. User registration and login.
6. Responsive design for all devices.
7. Fetch dynamic product data from an API.
